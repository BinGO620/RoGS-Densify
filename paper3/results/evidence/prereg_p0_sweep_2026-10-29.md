## 1. 要检验的假设

Phase 0 已确立：同等预算下 persistence 排序相对 off 无 ATE 收益（Δ=+0.36cm，地板内），
且终态高斯数膨胀 1.332×。当前最具解释力的候选假设是：

> **H1（收缩项有害）**：`e_i = accum/(denom + p0)` 中的 `p0` 把 `denom` 小的点放大，
> 使选择器优先在几何证据最弱处插入高斯。收缩越强，危害越大。

H1 的可测推论：ATE 应随 `p0` 增大而单调变差。

**替代假设 H2（收缩项无影响）**：`p0` 在 [0,128] 内对 ATE 无可分辨影响 ⇒ 问题不在收缩项，
而在排序项本身、或机制对动态场景本就无效。此时 H1 证否，需转向别的解释。

**替代假设 H3（收缩项有益）**：ATE 随 `p0` 增大而改善 ⇒ 收缩项方向正确，Phase 0 的零收益
来自别处。

## 3. 内建正确性校验（p0=0）

`p0=0` 时 `e_i = accum/(denom + 1e-6) ≈ accum/denom` = **平均梯度**，
而 off 臂的选择规则正是「平均梯度 ≥ τ_base」。因此：

- **C1（必要条件）**：`p0=0` 臂的逐事件 `budget` 序列应与 off 臂逐事件相等。
- **C2（严格条件，需要产物）**：`p0=0` 选中的点集合应与 off 的 P0 **逐位相等**。

**已知限制**：`console.log` 目前只落 `iter/pool/budget/accepted/mean_p/fallback`，
**没有落选点索引**，因此 C2 无法在本次扫描中检验，只有 C1 可查。
**C1 不通过 ⇒ 实现有偏差**，此时扫描结果全部作废，先修实现。
**C1 通过但 C2 未验 ⇒ 不得声称「p0=0 严格复现 off」，只能称「计数口径一致」。**

另注：`get_bpw_config` 对 p0 有 `max(float(p0), 1e-6)` 保护，故 `p0: 0` 实际执行值为 1e-6。
这对量级无影响，但严格来说不是「恰好 0」，论文中不得写成「p=0」。

## 4. 判定规则（机械可判）

设 `ATE(p)` 为 p0=p 时的全帧 ATE。

- **R1（正确性门）**：若 C1 不通过 ⇒ 全部作废，不进 R2–R4。
- **R2（H1 成立）**：存在 `p_a < p_b` 使 `ATE(p_b) − ATE(p_a) > 0.62cm`
  **且**该方向在相邻点对中至少出现 2 次（即单调变差至少跨两段）。
  ⇒ 记「收缩项有害，强度依赖成立」。
- **R3（H2 成立）**：所有 `|ATE(p) − ATE(8)| ≤ 0.62cm` ⇒ 记「收缩强度在 [0,128] 内不可分辨」。
  ⇒ H1 证否，Phase 0 零收益不能归因于收缩项。
- **R4（H3 出现）**：若 `ATE(0) − ATE(8) > 0.62cm`（即零收缩反而更差）且方向跨点一致。
  ⇒ 记「收缩项有益但与 Phase 0 的零总收益矛盾」，需另找抵消源。
- **R5（其余）**：非单调、或在 0.62 边缘抖动 ⇒ 记「不可判」，**不得挑对自己有利的片段讲故事**。

## 5. 明确不主张的事

- 不主张 H1 的效应量（单 seed、单序列）。
- 不用本扫描的 ATE 差值替换 Phase 0 预注册的 PASS/FAIL 判据。
- 不因某个 p0 恰好更好就改基准 p0 并重跑 Phase 0（那是事后调参，禁止）。
- 本扫描不能回答「更少高斯能否达到相当 ATE」——那是 budget_scale 曲线的事，另开。
