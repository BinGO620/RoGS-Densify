## 0. 为什么本文件不是「冻结地图」，而是「冻结剂量计划」

② 在账本里的原话是：「先跑一次 off 并逐事件 dump 地图快照，两臂选点都在**同一条地图
轨迹**上做，剂量逐事件严格相等，反馈环被切断」。零 GPU 探针（`fdose_feasibility_2026-10-31.md`，
复现脚本 `scripts/paper3_bpw/probe_frozen_dose_feasibility.py`）读出两条装置事实，
**字面形式不可构造**：

| 读数 | 值 | 后果 |
|---|---|---|
| **Q1** 跨臂位置对应：g0 的参考点在本臂同事件的全体点里 1e-4 m 级重合率 | 事件 1 = **1.000**；之后 **0.000**（均值 0.0179）；最近点距中位 0 → **0.0156 → 0.0862 m** | 快照里的点**喂不进**另一臂的活地图：两臂从事件 2 起点集就已经对不上（1 cm 级仅重合 22%） |
| **Q2** 用 trace 记录的完整选择器输入（`mean_grad`/`denom`/`sparsity`）重放 top-k | g1 **62/63**、g0 **61/61** 逐位复现 | 选点是**逐事件冻结状态的确定性函数** ⇒ 能冻结的是**状态到选择**这一段，不是地图本身 |

⇒ 可构造的最大化形式是：**冻结「每个事件加多少个点」这个标量计划，两臂各在自己的地图上
按自己的键取恰好 K_i 个点**。剂量因此成为**外生**（由计划文件给定，不再由自身地图的新增计数
决定），两臂逐事件剂量严格相等且**可事后从 trace 复核**。

**它切断了什么、没切断什么（必须明写）**：

- ✅ 切断：剂量对自身放置结果的依赖。CGB 的两臂 `ref_sel` 从事件 2 起分叉（共同 56 事件
  Σ 差 +7.79%）正是这个环；FDose 下 K_i 来自外部计划，两臂不可能在剂量上分叉。
- ❌ 未切断：**地图状态**仍由各自历史决定（在线 SLAM 的固有性质），所以两臂的**候选集**
  仍然不同 ⇒ 本实验的估计量是「同一外生剂量计划下，不同排序键造成的地图差异」，
  **不是**「同一张地图上的受控对照」。这一点在判决措辞里不得越过（见 §8）。
- ❌ 未切断（**本轮新量，必须写进判决**）：**序数对齐只是名义对齐**。两臂的 densify 事件由
  `iteration_count % gaussian_update_every` 触发，而这个计数器按 mapping 调用推进；实测同
  config、只差 `gamma` 的两个 CGB 臂事件**数**就不同（**63 vs 61**，末事件分别在
  iter 9,200 与 9,650），且第 j 个事件在**时间轴**上错开
  ——以 g0 vs g1 的既有 trace 量：`iter_g1(j) − iter_g0(j)` 中位 **−300**、|差值| p90 **750**、
  最大 **900**（一个事件间隔约 150 iter ⇒ 序数相差可到 **6 个事件**）。⇒ 「同样多」成立，
  「在同样的地图时刻注入同样多」**不**成立。计划若改成按 iteration 累积对齐，则注入总量会
  少 **9.5%**（实测：以 g0 的计划给 g1 累积对齐，Σ注入 232,354 vs 目标 256,686）。
  两害取其轻选**按事件序号投递**，并逐事件报该偏移分布（R7）。

> ⚠ **2026-10-31 更正（slam-critic M2；原文不追改）**：上一句原先写「序数对齐全量投递」，
> 与 §2 末段的 **`N_plan` 截断**（序号 ≥ N_plan 注入 0）自相矛盾 —— 截断本身就主动丢弃
> 尾部剂量。正确陈述：**保住的是「前缀 N_plan 段的全量」，尾部按 N_plan 丢弃**；
> 实测在三条 580 帧 trace 上前缀 57 只占 k0 总量的 **78.4% / 82.7% / 87.3%**
> （事件数 64 / 63 / 61）。「按 iteration 累积对齐会少 9.5%」这条论证仍然成立，
> 但它比较的是两个**都会丢剂量**的方案，不是「全量与截断」之别。

> ⚠ 本节是对 ② 的**收窄**，不是放弃 ②。判定依据是 Q1（快照不可移植）+ Q2（选择可重放），
> 两条都是可复跑的读数，不是推理。收窄本身入账 `P3-D2-010`，用户可凭账本否决（R6）。

## 1. 假设

> **H1（外生等剂量下，放置可分离）**：在每个 densify 事件加**恰好同样多**源点的前提下，
> 把新点放到「空间稀疏处」（S 臂）比放到「梯度最强处」（G 臂）更能改善跟踪。

- H1 成立 ⇒ 存在与剂量无关的**放置效应** ⇒ 这是可主张的正面机制。
- H1 不成立（S ≥ G）⇒ 「更多」就是「更多」/ 扩散价不换跟踪 ⇒ 本族止损（记 `NOTES.md`
  「已排除方向」，**不合并进 BPW 的表述**）。
- S 与 G 都劣于 k0 ⇒ 剂量本身有害这一支**本实验不判**（k0 与两臂的注入形态不同，
  见 §2 最后一段），只作报告项。

## 2. 机制定义（一句话可复现）

计划来源 = k0 臂（**参考剂量臂**，无选择器，`K_i = |ref_sel(i)|`，即基础规则自己的选择数）。
计划在 G/S 两臂**开跑前**从 k0 的 trace 冻结成文件 `dose_plan.json = {iter: K}`。

每个 densify 事件（G/S 两臂同一套代码，只差 `gamma`）：

```
K_i    = dose_plan[i]                        # 外生；两臂逐事件严格相等
pool   = { i : g_i >= τ_lo }                 # τ_lo = tau_low_factor · τ_base
key_i  = g_i · s_i**gamma                    # gamma=0 → G 臂；gamma=1 → S 臂
sel    = pool 内 key 最大的 K_i 个            # 恰好 K_i 个
选中者阈值 −1.0，其余 +inf；percent_dense 一律不变
```

`g_i = accum_i / max(denom_i,1)`；`s_i` 用与 CGB 完全同一实现（`compute_sparsity`，k=6，
体素自校准、无标定常数）。

**与 CGB 的两处关键差别**：

1. **不再保留参考集**。CGB 保留 `ref_sel` 再加 5%，实测保留部分占注入剂量 **95.2%**
   （共同事件 Σref 240,385 / Σtotal 252,375）—— 也就是「等剂量」管的是 5% 那一小块，
   而分叉发生在 95% 那块。FDose 取消保留项，**总剂量整体外生**。
2. **K_i 可以是负数方向的修剪**。若本臂自己的 `|ref_sel|` > K_i，则本事件少选点即
   「修剪」；探针实测这种情况真的出现（以 g0 的计划给 g1：相对自身参考数中位 **−1.57%**、
   极值 −22.15% ~ +69.99%）。⇒ **修剪幅度必须报事件级分布**，不得只报中位。

**计划长度 N_plan 与越界规则（关键，决定总剂量是否真的相等）**：

两臂的 densify 事件**数**不同（同一 config 家族实测 61 / 63 / 64），所以计划必须有一个
**固定长度 `N_plan`**，并且**事件序号 ≥ N_plan 之后注入 0**（不是沿用末位剂量——那会让
事件多的臂多拿那部分，总剂量又随事件数分叉）。⇒ 两臂总注入量 = 计划前缀和，**与各自
事件数无关**。**N_plan 的取法**：既有 580 帧 run 的事件数实测 **61 / 63 / 64**（三个样本），故取
`N_plan = 57`（留 4–7 个事件的余量），由 `make_dose_plan.py --n-plan` 落成 `N_plan` 字段。
⇒ 只要两臂都跑满 ≥57 个事件，**总注入量逐臂严格等于计划前缀和、与事件数无关**
（冒烟实测：19 事件的 k0 与 17 事件的 G/S，两者 Σsel 都等于计划 ΣK = 23,979）。

> ⚠ **等总剂量是前提，不是保证**：若某臂触发的事件数 < N_plan，它就只注入了前缀的一部分
> （例如只跑 50 个事件 ⇒ 少注入末几段）。**F5 正是为此设的**：两臂 Σsel 都必须等于计划 ΣK，
> 任一臂短触发 ⇒ F5 失败 ⇒ 装置失效，**不得**解释机制。这条不写进"自动容错"：
> 少注入不是可以折算的剂量差，而是对照本身不成立。

**两个 densify 站点共用同一个事件序数（必须登记）**：

事件由**两个**站点推进，同一个 `ordinal` 计数器跨越它们：

| 站点 | 触发条件 | 冒烟里的 `ord` 段 | 剂量占比 |
|---|---|---|---|
| `initialize_map` | `mapping_iteration % init_gaussian_update(=100)` | `0..10` | **49.0%**（ΣK = 11,759 / 23,979） |
| `map()` | `iteration_count % gaussian_update_every(=150)` | `11..` | 51.0% |

⇒ **`N_plan=57` 的截断只砍尾部 map 事件，init 段 100% 保留。** 两个站点的
`scene_extent` 不同（`cameras_extent × init_gaussian_extent` = **180** vs
`cameras_extent × gaussian_extent` = **6.0**，`cameras_extent=6.0`），所以同一条
`percent_dense` 在两个站点的 clone/split 界也不同（**1.80 m** vs **0.06 m**）——
剂量形态因此是分段的。判据机按站点分列报（`F1_init` / `F1_map`），R2 分站点报。

**k0 的等价性**：k0 = `signal: "frozen_dose"` + `dose_plan_path: null`（自计划，
K_i = 自身 `|ref_sel|`）。它在本事件的选点与基础标量规则**逐位相同**（top-K by mean_grad
at τ_lo ∩ K=|ref| 恰好回到 τ_base 选择，唯一差别是浮点边界的平局处理），
⇒ k0 可直接当剂量参考臂，**不需要**另行重跑既有 off 臂。

**数值核验（2026-10-31，用两条已有 CGB trace 的冻结状态独立复算）**：在池
`{g ≥ τ_lo}` 内按 `mean_grad` 取 `|ref_sel|` 个最大的点，与 trace 记下的 `ref` 集合比对：
g1 臂 **63/63 逐位相同**，g0 臂 **60/61**（唯一不同的事件对称差 = 0.04%·K，即浮点平局）。
⇒ 等价性主张成立，且平局风险可忽略（另测：10 个事件 33,664 个点里，`|g − τ_base| < 1e-9`
的只有 **4 个**）。

- **R2 剂量代价**：`ΔATE(G − k0)`、`ΔATE(S − k0)`，**报告项**（两臂与 k0 的注入形态不同，
  不参与 PASS/FAIL）。⚠ **这个对比按设计就带剂量差**：k0 跑满全部事件，G/S 只投递计划前缀
  `N_plan=57` 段 ⇒ 实测在既有 trace 上，前缀 57 只占 k0 总量的 **78–87%**（取决于事件数
  61/63/64；末 4 个事件本身携带 11–13% 的剂量）。⇒ **不得**把 `G−k0`/`S−k0` 读成
  「机制的剂量代价」，它读的是「少投约 1/8 剂量 + 换键」。
- **R3 终点状态**：`online_num_gaussians` 与 `refined_num_gaussians` **两列并陈**
  （CGB 教训：8 臂中 2 臂两列差恰好 +5,000 = 一个 `Candidate insert KF` 末端竞态；
  单列引用会被骗）。
- **R4 放置剖面**：每臂每事件的选中点平均 `s`、平均 `mean_grad`、以及事件级修剪/加注幅度
  分布（中位 + IQR，不用单点 mean）。
- **R5 渲染**：`mask_type=static` 行的 PSNR / SSIM / LPIPS / depth-L1（全帧行恒 NaN，
  Bonn 已知陷阱）。
- **R6 候选集漂移（必须报，本设计的主要残余混杂）**：同序数事件上两臂 `|pool|` 的相对差
  中位 + IQR、候选集交集占比。它是「地图状态未切断」的量化痕迹。
- **R7 序数—时间错位（必须报，§0 第三条未切断的量化）**：同序数事件的
  `iter_A(j) − iter_B(j)` 中位 + p90 + 极值，以及两臂**事件总数**之差。若两臂事件数差
  > 2 或 |偏移| p90 > 一个事件间隔，判决里必须明写「剂量按数量相等，不按地图时刻相等」。

## 5. 功效核算（`PREREGISTRATION.md` §3.2(b) 强制项）

**sd 的来历**（两个来源，取保守者）：

| 来源 | 数据 | sd |
|---|---|---:|
| A：`person_tracking` 同批 on−off 逐 seed 配对差 | 3 seeds，`+0.2219 / +0.4995 / +2.9327` cm（bpw_on vs bpw_off，580 帧） | **1.491** |
| B：同 config 同 seed 的**零对比**装置地板 | `off` vs `off_trace`（只差 `trace_selection`）：ATE 差 **+0.9514 cm** | 0.951（单对，当 sd 用偏乐观） |

`MDE(95%, n) = t(0.975, n−1) · sd / √n`：

| sd 来源 | n=3 | n=4 | n=5 | n=6 | n=8 |
|---|---:|---:|---:|---:|---:|
| **A = 1.491（采用）** | **3.70** | 2.37 | 1.85 | **1.57** | 1.25 |
| B = 0.951 | 2.36 | 1.51 | 1.18 | 1.00 | 0.79 |

- **设计层已知缺陷（必须在跑之前声明）**：n=3 时任何 `|ΔATE| < 3.70 cm` 的效应
  **本实验不可能判出**。本序列的序列地板（取最保守）为 **3.83 cm**，两值同量级
  ⇒ 本设计的判读阈值与序列地板一致，不存在「地板小、MDE 大」的自相矛盾。
- **n=3 的用途只有一个**：判断是否需要扩到 n=6。**不得**把 n=3 的方向读数写成结论。
- 若 n=3 落在 §6 规则 5 的延长区，扩到 n=6（MDE 1.57 cm）；**n=8（MDE 1.25 cm）为上限**，
  再不够就按「不可判」收尾，不加 run。

### 5.1 可达域（exp32「先算可达域」强制项）

等**总剂量** K = `|ref| + floor(0.05·|ref|)` 时，两条键能拉出多大差别（探针实测，逐事件）：

| 键（对 `g` 的相对表现） | 平均稀疏度比 | 平均梯度质量比 | Jaccard(与 G) |
|---|---:|---:|---:|
| `g`（G 臂，基准） | 1.00× | 1.000 | 1.000 |
| **`g·s`（S 臂，γ=1，本设计采用）** | **1.35×** | **0.925** | **0.569** |
| `g·s²` | 1.42× | 0.853 | 0.448 |
| `s`（纯稀疏） | 1.46× | 0.680 | 0.309 |

⇒ **本设计的机制强度上界 = 平均稀疏度拉高 ~35%、平均梯度质量降 ~7.5%，两臂重合 ~57%**。
（对照：CGB 的「仅额外点」口径能到 2.9–3.3×，但那是只比较 5% 的点，不是总剂量。）
**若「扩散 35%」这个强度的真实效应小于 §5 的 MDE（1.57 cm @ n=6），本设计就判不出来**
——这是设计层缺陷，跑完不得用「机制被抑制」之类的话术解释。

γ 锁定 **1.0**（与 CGB 预注册同一值）。调 γ 属参数扫描，须另开预注册（`§9` 禁止事项）。

## 6. 机械判定规则（看数据前锁定，按顺序应用）

1. **装置失效**：F1–F5 任一不过 ⇒ 冻结读数、修装置、按原判据重跑。**不得**解释机制。
2. **方向 + 显著**：`ΔATE(S − G)` 三 seed 均值 **< 0** 且 `|Δ| ≥ 3.70 cm`（= n=3 的 MDE）
   ⇒ **放置可判**，进 L2（补 2 条不同类型序列：`balloon` 非退化 + `crowd` 密度；
   并在 L2 开工前用本轮 seed 间散布重算 n=3 的 MDE）。
3. **反向 + 显著**：均值 **> 0** 且 `|Δ| ≥ 3.70 cm` ⇒ 「外生等剂量下稀疏放置更差」，
   **本族止损**，记 `NOTES.md`「已排除方向」（与 BPW 并列，不合并叙述）。
4. **落在延长区**：`|Δ| < 3.70 cm` 且三 seed **方向一致**（3/3 同号）⇒ 允许扩到 **n=6**
   （上限），用 n=6 的 MDE **1.57 cm** 重判。若 n=6 仍 `|Δ| < 1.57` ⇒ 转规则 5。
5. **不可判**：`|Δ| < MDE(该 n)` 且方向不一致，或在 n=8 时仍不过 ⇒ 判 **「不可判」**，
   写进 `NOTES.md`「已排除方向」的**同一条**（与 BPW/CGB 并列），不作任何效应主张。
6. **剂量代价报告**（不参与 PASS/FAIL）：`ΔATE(G − k0)`、`ΔATE(S − k0)` 两两并陈；
   若两臂都 `≥ k0 + 3.83`，在判决里加一句「注入剂量本身的代价与放置效应同量级」，
   **但不得**据此把方向项改判为剂量有害（形态不可比，§1 已登记）。

> 规则 2/3 的「显著」是**跨 seed** 口径；逐帧块自助 CI 仍要报（它是「这 580 帧内方向是否
> 一致」的证据），但它**不是**效应量，不得单独用于过门（CGB 的措辞纪律）。

## 8. 本预注册不主张什么

- ❌ 不主张「两臂在同一张地图上选点」——只有**剂量**外生，候选集仍各自长（§0、R6 量化）。
- ❌ 不主张对 CGB 判决的任何追溯修改（BPW/CGB 的判决不追溯）。
- ❌ 不把本实验的 number 当作论文表数字（本地非权威）。
- ❌ 不用「机制被抑制」「覆盖饱和」之类的命名式结论包装负结果（`DISCIPLINE.md`
  负结果处理条）：失效分析只出现在「下一步止损/改善」位置。
- ❌ 不主张两臂的**索引可对应**：冒烟实测同事件索引位置重合率 0.000、5 cm 内匹配率
  0.95 → 0.40 递减 ⇒ 任何跨臂索引比较（含原 F3 的 Jaccard）都测的是地图分叉
  （Amendment A1 §1）。F3 因此改为**臂内**稀疏度剖面。
- ✅ 只主张一条可复核的装置事实：**在「两臂各自在线生长地图」的基座上，
  「等剂量」唯一能外生控住的量是逐事件注入计数 K_i**（Q1 证快照不可移植、Q2 证选择可重放）。

## 9. 不许做的事

- 不许在看到 ATE 后调 `gamma` / `tau_low_factor` / seed / 序列重跑同一臂（参数扫描另开 prereg）。
- 不许把 k0 的 K 计划**在跑后**按 G/S 的结果重建（计划必须在 G/S 开跑前冻结并记 sha）。
- 不许把 n=3 的方向读数写成「证实/证否」。
- 不许只报 `online_num_gaussians` 或只报 `refined_num_gaussians`。
- 不许用 `latest_run()` 隐式取 run 目录（必须显式路径；`judge_p0a.py` 曾硬编码 `*_balloon` 静默取错）。
