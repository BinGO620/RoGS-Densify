# CGB 预注册 Amendment A1 — 剂量口径与"稀疏点是什么"（2026-10-30）

**账本**：`P3-D2-008`（CGB 族的预注册修正案；A1 = 剂量口径）
**上位**：`prereg_cgb_2026-10-30.md`（主预注册，判据锁定于看 ATE 之前）
**性质**：在 L1 **ATE 读数出来之前**提出的装置修订 + 两条实测。触发原因是在机制 trace 与
终点地图工件上做了读数，**不是**结果驱动。
**不允许**：不得用本 Amendment 改 `prereg_cgb` §6 的四条出口规则；它只改"剂量怎么算"、
并补充"稀疏点是什么"的证据。

---

## 1. 读数一：clone / split 两条路径的净增本来就相同，泄漏是二阶的

`densify_and_clone`：父点保留 + 1 个子点 ⇒ **+1**。
`densify_and_split`：父点被移除、换 2 个子点 ⇒ **+1**。
⇒ **每个选中源点的净增高斯数恒为 1，与路径无关**。所以在"逐事件净增"这一层，
`prereg_cgb` §0 的"两臂等剂量"是**成立的**，不需要修订 G1。

真正的差异是**二阶**的：split 会把子点缩小（`scaling/(0.8·N)`）并重置梯度统计，
clone 保留父点尺度。同一批源点数走不同路径，**下一次事件可被选中的点集不同** ⇒
剂量在**跨事件**上可能缓慢分叉。这一点在 `prereg_cgb` 里被写成"报告项"，而不是 gate。

**实测路径分布**（终点地图 N=70,694；`split 界 = percent_dense 0.01 × cameras_extent 6.0
× gaussian_extent 1.0 = 0.0600 m`，`slam.py:324` 硬编码 `cameras_extent = 6.0`）：

| 稀疏度分位 | n | 走 split 路径占比 | mean max-scale (m) |
|---|---:|---:|---:|
| 全体 | 70,694 | 7.5% | 0.0242 |
| s ≥ p50 (1.00) | 35,347 | 14.7% | 0.0367 |
| s ≥ p75 (1.80) | 17,674 | 27.1% | 0.0546 |
| s ≥ p90 (3.41) | 7,070 | **51.1%** | 0.0834 |
| s ≥ p95 | 3,535 | **68.6%** | 0.1086 |
| s ≥ p99 (10.24) | 707 | **91.2%** | 0.1754 |

`Spearman(s, max-scale) = 0.577`。⇒ γ=1 臂选的额外点**有一半以上走 split**，
γ=0 臂（按梯度选）走的是全场基线 7.5%。这是本设计里**唯一真实的混杂**。

## 2. 读数二：稀疏点不是"垃圾点"（这条支持继续做）

同一张地图，按稀疏度分级看可见性：

| 稀疏度分位 | sigmoid opacity | opacity < 0.05 占比 |
|---|---:|---:|
| 全体 | 0.905 | 2.2% |
| s ≥ p50 | 0.920 | 1.8% |
| s ≥ p90 | 0.971 | **0.3%** |
| s ≥ p99 | 0.977 | 0.0% |

⇒ 越稀疏的点 opacity **越高**。也就是说"奖励稀疏"没有在挑不可见/浮空的点；
它挑的是**大跨度、高置信、低密度**的曲面元素（典型：远墙、门框、天花板的少样本大高斯）。
这一条是机制可以成立的**前提**，必须写进预注册，因为它排除了"γ=1 只是在放大噪声"这一解释。

## 3. 处置（写死的机械规则）

**(a) 剂量门从"报告项"升为 gate（新 R2′）。**
`|net_g1 − net_g0| / net_g0 ≤ 5%`（终态高斯数）。超 5% ⇒ `ΔATE(g1 − g0)` **不得**解释为
放置效应——按 §6 第 2 条走（判剂量有害）或重跑。
5% 的来历：`phase0_event_k_floor_2026-10-28.md` 同臂同 config 同 seed 重跑终态高斯数相对差
中位 **2.83%**（439 帧），5% ≈ 2× 该装置地板。**不是**拍的整数。

**(b) trace 增加 `max_scale` 列**（与 `trace_selection` 同一默认关开关）。
作用：把上表从"终点推断"升级为**事件级读数**（每次事件时两臂选中点里有多少走 split）。
列只增不改，历史 trace 缺列时该分析显式报 missing 并跳过。

**(c) 不引入尺度惩罚项 / 不引入尺度奖励项。**
`Spearman(s, max-scale) = 0.577` ⇒ 奖励 `s` 已经**顺带**偏向大尺度点。
把 `max_scale` 显式放进键会让效应无法归因（且等价于偷偷放大 γ）。本族只测"奖励稀疏"。

## 4. L1 判读顺序（Amendment 后）

1. 机制门 G1/G2/G3（`scripts/paper3_bpw/check_cgb_gate.py`）——装置。
2. **剂量门 R2′**：`|net_g1 − net_g0|/net_g0 ≤ 5%`。
3. 1、2 都过 ⇒ `ΔATE(g1 − g0)` 才允许读作**方向**信号（§5 功效约束不变：
   单 seed 一律"不可判"，只用于决定要不要补 seed 1/2）。

## 5. 边界（本 Amendment 明确不覆盖）

- **不覆盖"稀疏 vs 大尺度"的不可分离性**：γ=1 同时选了"更稀"和"更大"的点（ρ=0.577）。
  本设计**不能**把效应唯一归因于"空间稀疏"。要分离须另开"固定尺度、只换位置"的臂 ——
  本族不做，但**论文/汇报里不得写成"稀疏致密化有效"**，只能写
  "按 kNN 稀疏度加权选点（该键与大尺度正相关）"。
- 不覆盖源点数口径（G1 仍按源点判，因为那是机制定义）。
- 不覆盖跨 seed 的剂量稳定性（L1 单 seed，只报值）。
