## 0. 问题（为什么要做这个）

现在所有机制判决都是**臂级终态**（ATE / 高斯数）。它有一个根本盲区：

> **「机制没工作」与「机制工作了但 ATE 没变」在臂级终态上完全相同。**

MinObsGate 的 CLOSED_NO_EFFECT 就是典型：Δ 异号、median 不过门。
但我们**不知道**是：
- (a) 门真的把一部分高斯挡在 clone/split 之外，只是对 ATE 无影响；还是
- (b) 门根本没生效（比如 denom 分布使 N=8 几乎不截断任何人）。

**E2 的作用：直接判「机制是否改变了逐 densify 事件的决策」，不经过 ATE。**

## 1. 前置链（框架 §E2 明文要求，三步全未做）

### P1 逐事件机制输入量落盘（两臂都要有）
在 `densify_and_prune` 调用点，逐事件落盘：
- `iteration`、事件序号
- **机制输入量**：`denom`（观测计数）的分位数（p10/p50/p90）、
  `mean_grad`（accum/denom）的分位数
- **机制作用量**：被门槛排除的数量（`n_gated`）、实际 clone/split 数
- 落盘门 = 新 config 键 `E2.trace_events`（**默认 false** ⇒ 逐位不变）

### P2 逐事件装置地板（同确定性状态 + 同事件载体）
- 仪器口径（单线程 + det-raster）+ trace on，**同臂同 seed 重跑 ≥3 样本**
- 地板 = 逐事件指标的中位相对差
- **禁用**：任何 det-OFF 或无 trace 的旧样本（框架明文）

### P3 n 与 MDE 声明
- 每臂 n≥3；先落「若真实效应 < MDE，本设计判不出」的声明（MDE 由 P2 地板算）

## 2. E2 判据（框架 §E2 机械化，不自创）

对每个逐事件指标 m（`n_gated` / `denom_p50` / `grad_p50` / `n_added`）：

跨臂配对差 Δ_m = median(m_on − m_off)（同 iteration 配对）
地板 Δ_floor = P2 中位相对差

- **Δ_m ≥ 2 × Δ_floor 且两参照方向一致** ⇒ 该指标「跨臂行为分叉」（机制确实改变了事件决策）
- 否则 ⇒ 「装置分辨率内不可判」
- 出口**只允许**「分叉 / 不分叉」级别结论，**不得**升格为性能主张（框架 §4）

## 3. 首批执行对象（用已有臂，不新开机制）

**用 MinObsGate 两臂**（`minobsgate_off` / `minobsgate_on`）做 E2 的**首次落地**：
- 它的 CLOSED_NO_EFFECT 正是最需要 E2 解释的案例
- 若 E2 判「分叉」⇒ 机制确实生效、只是 ATE 无感 ⇒ MinObsGate 可从
  「不可判」改判为「生效但无性能效应」（这是**新的、更强的结论**）
- 若 E2 判「不分叉」⇒ 机制根本没生效 ⇒ 失败原因定位到实现/参数层，可修

**装置**：3090，仪器口径，seed 0，全长 580 帧，每臂 3 run（2 个地板样本 + 1 个跨臂样本）。

## 4. 不主张

- E2 不产生性能主张，不产生贡献。
- 「分叉」不等于「机制有用」——只证明它改变了决策路径。
- 若 E2 判不分叉，**不得**据此宣称机制族关闭以外的任何事。
