# 剂量-响应筛查预注册（ADC 梯度阈值 τ 扫描）—— 2026-11-04

**状态**：判据锁定于任何新 run 之前。账本：`P3-D2-018`（本轮立项，见 DECISIONS）。
**性质**：**L1 机制筛查（n=1，1 seed）**，按「渐进阶梯」与纪律 #11，n=1 一律不可判；
本批只产**剂量-响应形态**（报告项）与装置事实，不得写任何效应结论。

## 0. 问题与动机

FDose（`P3-D2-015`）已证「等剂量下换放置键」无 ≥1.57cm 可测效应；MaskStat L1
（`P3-D2-017`）两 seed 方向相反但两 seed 的**剂量收缩幅度与 Δ 符号同向**（收缩
−18.5% ⇒ +2.04cm；−5.0% ⇒ −1.29cm）。两条线索共同指向一个从未直接测过的量：
**在在线动态 RGB-D SLAM 里，ATE 对致密化剂量本身有多敏感？**

它同时是论文 3 叙事的枢纽：TopoGS-SLAM（2601.00705）在静态室内主张「中等基元数即饱和、
继续致密化只涨内存」——若该论断在**在线动态**设定也成立，剂量约束的价值边界与论文
定位都要改写（gap_note 已登记该风险，讨论节必答）。

## 1. 设计（单变量、零代码改动）

- 唯一变量 = `Training.densify_grad_threshold`（ADC 主阈值 τ；原版单键，非本仓机制）。
  τ↑ ⇒ 更少高斯；τ↓ ⇒ 更多高斯。
- 臂：`τ_scale ∈ {0.5, 1, 2, 4}`（绝对值 0.0001 / 0.0002 / 0.0004 / 0.0008）。
- **1× 臂 = 复用今日 `maskstat_off` seed0 全长 run**（`2026-11-04-03-22-44`，9.3029cm）：
  同 HEAD、同 seed、同 config 链（该 config 与 bpw_off 逐字段差异仅输出路径，已复算）。
  ⇒ 只需新跑 3 个 run（0.5×/2×/4×），≈2.5h（本地 2060；3090 拒连则标 provisional）。

## 2. 装置门（先于任何读数）

- **D1 剂量真的变了**：终态高斯数 `num_gaussians` 随 τ 单调不增（τ=4× ≤ 2× ≤ 1× ≤ 0.5×，
  允许 ±3% 装置抖动带）。若单调性不成立 ⇒ 装置失效，冻结读数、不加 run。
  ⛔ **±3% 带已被装置自差证据废止为判效带宽（2026-11-05，P3-D2-023 乙案）**：3090 同
  config 同 seed 自差 −30.3%~+96.8%，门带宽 << 装置噪声。D1 作为机械出口的历史角色
  不变；此后臂级判读按 `prereg_device_gate_2026-11-05.md` Part A2 执行。
- **D2 因果孪生**：同 `rng_sequence`、同 seed、`--seed 0`、同数据链。
- **D3 帧数闸**：全长 580 帧（40 帧冒烟不得混入）。

## 3. 读数与形态判读（n=1，只作报告）

- 主读数：ATE（`ate_rmse_cm`）对 τ_scale 的**形态**：单调升 / 单调降 / U 形 / 平台。
- 次读数：终态高斯数（剂量代理）、online/refined 高斯数、每 run 时长与显存。
- 判读口径（事先写死）：
  - 平台（四臂 ATE 极差 < 逐序列地板 3.83cm）：**形态与 TopoGS 同向**（剂量不敏感区）；
  - 单调（>3.83cm 跨度）：剂量敏感，方向记入；
  - U 形：存在工作点，记录位置。
  **任何形态都只写「筛查形态」，不写效应量、不写显著、不写「因此机制应……」。**

## 4. 出口规则（按序）

1. 装置门 D1 不过 ⇒ 记 `DEVICE_FAIL`，本批作废，不加 run。
2. D1 过 ⇒ 出 `dose_response_screen_2026-11-04.md`（形态表 + 曲线 + 三口径剂量），
   标 provisional。
3. 形态为「单调」或「U 形」且跨度 > 地板 ⇒ **允许**申请扩 2 seeds（另判，不在本批范围）；
   形态为「平台」⇒ 写进讨论素材（与 TopoGS 互证），扩批须先有新动机。
4. **本批不产生任何机制、不产生贡献主张**；负结果/不可判均按纪律 #11 处理。

## 5. 时间盒

- 硬顶：本批启动后 **3.5 小时**（3 run ≈2.5h + 判读 0.5h）；到点按已完成 run 收尾，不加 run。
- 失败处置：单 run rc≠0 ⇒ 记 FAIL 不补跑凑数。

## 6. 不主张什么

- n=1 不构成效应结论；四臂 ATE 的差异只描述形态，不作显著性或因果表述；
- 剂量变化本身不是收益；「平台」不等于「致密化无用」（它只说明该序列该区间不敏感）；
- 本批全部产自本地 2060 ⇒ provisional，进论文表须远程 3090 复跑。
