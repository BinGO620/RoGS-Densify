## §1 设计

### 臂
| 臂 | 配置 | 唯一差别 |
|---|---|---|
| `off` | `instrument_maskstat_off` | 基线（`Mapping.maskstat_dens_stats` 缺省 false） |
| `on` | `instrument_maskstat_on` | `Mapping.maskstat_dens_stats: true` |

两臂由 `make_instrument_arm.sh` 从 `maskstat_off/on_person_tracking.yaml` 派生，
**机制键原样继承**（契约单测守护：派生文件不得再写机制键）。

### 种子与重复
- **seeds 0 / 1 / 2**，每 seed × 每臂 **1 run** = 6 run。
- **R-valid 抽样复算**（§2）：off 臂 seed 0 与 on 臂 seed 0 各额外 1 run = **+2 run**
  （合计 8 run）。理由：仪器模式的理论保证是「同 config 同 seed 逐位一致」，
  但每次新增机制臂都要重新验证一次（on 臂比 off 臂多跑 MaskRCNN，
  有新的潜在非确定源）。两臂都验，不只验 off。

### 序列与长度
- `person_tracking`（唯一 headroom 序列；原族地板 3.83cm 是 async 口径的，本件不用）。
- **全长 580 帧**。理由：ATE 是整条轨迹的统计量，40 帧读数的绝对值与全长不可比；
  原族判决也在全长下做过。
- 20 帧级只用于**冒烟防崩**，不产生判据。

### 算力
本地 2060 单卡串行（仪器模式设计上就是一卡一线）。全长 580 帧约 40min/run
⇒ 8 run ≈ 5.3h。若中途需中止，按 §5 时间盒处理。

## §2 仪器前置（R-valid，每臂每批必验）

**R-valid**：`compare_three_way.py`（易变列剔除口径）判 `R1_bitwise_identical`。

| 检查 | 通过条件 |
|---|---|
| off 臂 seed0 两 run | R1 |
| on 臂 seed0 两 run | R1 |
| runner 自检 | 三项开关 + 三项环境全部在位（`run_instrument.sh` 内建） |

**任一不通过 ⇒ 整批作废**，先查开关是否真生效（不解释机制、不报数字）。

## §3 判据（机械，按序）

### 3.1 机制门（原族 G1–G5 沿用，装置无关）
- G1 关闭态逐位一致（单测，已有）
- G2 加权语义（单测，已有）
- G3 fail-closed（单测，已有）
- G4 trace 落盘：on 臂逐 mapping call 写 `maskstat_trace.csv`
- G5 RNG 无扰动（掩码计算 no_grad + 无随机算子）

**G4 作用量下限**（沿用原族规则 2）：`share_w_lt_1 < 5%` 或 `mean_w > 0.98`
⇒ 机制无作用量，止损记「已排除方向」。

### 3.2 主判据：逐 seed 精确 ΔATE

仪器模式下同一 seed 的 off/on 各自逐位可复现 ⇒

```
ΔATE(seed s) = ATE_on(s) − ATE_off(s)      ← 精确值，无装置噪声
```

（这是本件与原族最本质的区别：原族 Δ 里混着 ±2.14cm 的装置自差，
现在装置分量恒为 0。）

**判读规则**：

1. **方向一致**（三个 Δ 同号）**且** `|median(Δ)| ≥ 0.5cm` ⇒
   记「**机制有跨 seed 方向一致的效应**（方向如实记录，量级如实报告）」。
   *（0.5cm 门槛的理由：仪器口径下 Δ 是精确值，剩下的不确定性只来自 seed 抽样；
   0.5cm 约为 person_tracking 上 ATE 的 4%，低于此量级不主张，避免把数值抖动
   当机制效应。）*
2. **方向一致但** `|median(Δ)| < 0.5cm` ⇒ 记「**机制效应小于本设计可主张的下限**」。
3. **方向不一致**（有正有负）⇒ 记「**跨 seed 不稳定**」，不主张效应。
4. 任何出口都**不**写「改善/退化」以外的因果解释；`absolute ATE ≤5cm` 的目标
   检查单列（见 §4）。

### 3.3 副判据：剂量（报告项，不参与 PASS/FAIL）
- 终态高斯数比 `on/off` 逐 seed（仪器口径下也是精确的）。
- `maskstat_trace.csv` 的 w 分布（mean/min/share_lt_1/share_eq_0）。
- 剂量变化**不是收益证据**（P3-D2-004 教训原样沿用）。

## §6 本 prereg 不主张什么

- 仪器口径的绝对 ATE **不可**与旧批次/文献直接比（口径不同）。
- 只跑 `person_tracking` 一序列 ⇒ 不主张跨序列泛化。
- 剂量下降不是收益；「不退化」不是贡献。
- 评测协议/仪器本身**不是贡献**（框架 v2 §4 继续有效）。
