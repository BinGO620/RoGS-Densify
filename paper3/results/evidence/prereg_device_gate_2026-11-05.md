## Part B — 决定性模式探针预注册（P3-D2-024，判据先行）

### B1 问题

3090 的同 config 同 seed 分叉（−30%~+97%）是否可被 PyTorch 官方确定性套件消除？
**可 ⇒ 甲复活**（该装置在确定性模式下门带宽可回小值，臂级判效有救）；
**不可 ⇒ 丙坐实**（管线固有非确定性，atomicAdd 类 scatter 未排除，唯一出路是换估计量）。

### B2 设计（单变量：deterministic mode ON，其余全同）

- 配置：`configs/experiments/paper3_bpw/maskstat_off_person_tracking.yaml`
  （取自差证据最多的 off 臂配置），seed 0，全长 580 帧，**2 个 run**。
- 确定性套件（两 run 全开）：
  `CUBLAS_WORKSPACE_CONFIG=:4096:8`（cuBLAS 句柄创建前生效）、
  `torch.use_deterministic_algorithms(True, warn_only=False)`（fail-closed：
  非确定性算子直接 raise，不许静默退化）、`cudnn.deterministic=True`、
  `cudnn.benchmark=False`、TF32 关（`matmul/cudnn allow_tf32=False`，固定归约精度）。
- **注入方式 = 环境级，零核心代码改动**：`scripts/paper3_bpw/deterministic_probe/sitecustomize.py`
  经 `PYTHONPATH` 注入——`slam.py:680` 为 `mp.set_start_method("spawn")`，子进程
  （BackEnd/FrontEnd）不继承进程内 torch 标志，但 spawn 子解释器重新执行 sitecustomize
  并继承 `PYTHONPATH`/环境变量 ⇒ 全进程树覆盖。核心代码（`gaussian_splatting/`、
  `utils/`、`slam.py`）一字不动（纪律「代码保护」）。
- **顺序**：冒烟（40 帧 × 1 run）→ 装置核（见 B4-R3）→ 全长 × 2，**单卡串行**
  （`CUDA_VISIBLE_DEVICES` 单卡；逐位比对批次禁并发，沿用「测量口径」#5 精神）。

### B3 比对判据（跑前锁定）

对两全长 run 的判据件做**逐位比对**（md5 全文件，强于末行比对）：

- run 目录内：`tracking_raw.csv`、`per_frame_ape.csv`、
  `plot/{summary,trj_final,trj_full_final,stats_final}.json`（终态判据件）、
  `config.yml`——其中 `save_dir` 行含时间戳路径，**掩蔽该行后**再比对
  （时间戳本身不是行为变量）。
- 共享 `tables/efficiency_raw.csv` 与 `tables/mapping_raw.csv` 为**跨 run 追加模式**
  （非逐 run 文件）：每 run 结束时对该两表各取**末行快照**存入 run 目录，
  比对两 run 的快照（= 交接口径「tracking_raw/efficiency_raw 末行」的精确化）。
- 出口规则（按序，机械应用）：
  - **R1（逐位一致）** ⇒ 甲复活：该装置在确定性模式下重跑可复现，臂级门带宽允许
    按机重标定（**须**在确定性模式下重测自差地板——现有 3 样本地板是确定性关闭态
    测的，不直接沿用；且确定性模式的开销须一并核算）。重启甲须新 prereg，本探针
    本身不产生任何臂级判效。
  - **R2（任一判据件逐位不同）** ⇒ 丙坐实：torch 官方确定性套件不能消除该管线分叉，
    臂级读数维持 A2 降级；丙（逐事件配对/分布形态估计量）成为唯一有判效潜力的路径，
    须新 prereg。
  - **R3（冒烟或全长 run rc≠0）** ⇒ 记录 raise 的算子名即停：**管线含硬非确定性算子
    且官方套件无法关**，这本身就是 R2 级证据（不得用 `warn_only=True` 续跑——那只是
    把非确定性静音，探针失去判力）。允许一次有据修正（如漏设环境变量），第二次失败
    即按 R3 收口。
- 附带报告项（不参与 R1/R2）：确定性模式墙钟开销（vs 权威批同臂均值）、
  冒烟期 raise 算子清单（如有）。
