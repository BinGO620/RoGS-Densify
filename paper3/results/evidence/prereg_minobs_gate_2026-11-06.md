# MinObsGate（最小观测门）机制 prereg —— 2026-11-06 07:3x

**判据锁定于实现之前。** 候选池第 3 方向（`PROBLEM.md` §4）：
「对动态残差保留保守策略，避免把单帧异常直接放大为 clone/split」。
这是候选池**最后一个未测方向**（BPW/剂量已关闭、MaskStat 已判负）。

## 1. 机制一句话

**一个高斯要获得 clone/split 资格，必须先被观测支持 N 次；单帧异常（动态残差造成的
瞬时大梯度）没有触发资格。**

与 BPW（已关闭）的区别必须写死：BPW = 预算守恒的**名额重排**（给 persistence
最高者）；MinObsGate = **触发资格门**（观测不足者根本不进候选）。前者重排、
后者设槛，机制不同、出口独立。

## 2. 实现（复用现有通路，零核心模型改动）

- 信号 = `gaussians.denom`（自上次 densify 事件以来的渲染命中次数，BPW 同源）。
- `SelectiveDensification.signal: "obs_gate"` 新分支：`denom < N` 的高斯
  `thr_vec = +inf`（永不 clone/split），其余保持标量默认值。
- N **先验锁定 8**（与 window_size=8 对齐，同 BPW p0=8 的理由；跑后不得调）。
- 开关默认关 = `enabled: false` ⇒ 走原标量路径，逐位不变（单测级全等同 E1①）。

## 3. 判据（机械，按序；仪器口径 = P3-D2-030 标准 + itr=150 判读口径）

**臂**：`minobsgate_off`（纯基线，= instrument_maskstat_off 同链）/ `minobsgate_on`
（唯一差别 = SelectiveDensification 三键）。3090 卡0，全长 580 帧，n=3 seeds。

### M1 效应门（主判据）
|median ΔATE(on−off)| ≥ 0.5cm **且** 三 seed 同号 ⇒ M1 过（方向由符号读出）。
否则（不可判 / 低于地板）⇒ 机制无读数，关闭。

### M2 预算混杂门（贡献准入 §4，防「效果=更少高斯」）
|gauss_ratio − 1| ≤ 0.10 ⇒ 干净。> 0.10 ⇒ 效应与预算混杂，**只能记为
边界读数**，不得进贡献栏（预算守恒本是 BPW 的设计点，本机制天然不守恒，
所以这条门是硬性的）。

### M3 质量门
on 臂 PSNR ≥ off − 0.5dB 且 depth_l1 不劣化 > 10% ⇒ 通过；否则 M-TRADEOFF。

### M4 出口
- M1 过 + M2 过 + M3 过 + Δ 方向为**负**（on 更好）⇒ **正面读数候选**，
  进 9 序列扩展（第二场景复验）。
- M1 过但方向为正 ⇒ 负向，关闭（同 MaskStat 处置）。
- M1 不过 ⇒ 不可判/无读数，关闭。
- 任何出口不产生评测协议贡献主张。

## 4. 不主张

- 不预写机制有效性（判据先行）。
- M2 不过时不得用「高斯更少所以 ATE 好」叙事。
- 单序列结果不得外推（M4 正面读数必须过第二场景）。
