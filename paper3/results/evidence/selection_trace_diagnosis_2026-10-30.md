# 选点回放诊断：BPW 机制行为画像（2026-10-30）

**性质**：诊断（非判决）。回答"机制到底把点选在哪、换位有多大、方向是否合理"。
**触发**：用户要求先梳理项目（怀疑配置/开关）；Phase 0 复盘显示每事件选中
budget 个源点但 prune 大量反转，选点位置未落盘。
**数据**：`bpw_selection_trace.csv`（on 臂 person_tracking seed0，64 事件，
578,995 行；off 臂确认无 trace 文件 = 阴性对照）。
**复现**：见 §5。

## 1. 结论（三条，按证据强度）

1. **机制真实生效，不是 no-op，也不是随机**：accepted 点的 denom（观测计数）
   均值 171 / 中位 72，而被跳过的参考点（ref_passed）仅 9 / 5 —— 两个数量级的
   分离。p0=8 的收缩**没有**把排序压平。
2. **但换位规模很小（每事件 ~8%）**：每事件选中 ~4,250 个源点，其中 **88.4% 本来就是
   参考臂会选的**；真正被换掉/换入的只有 ~10%。被换入的 11.6%（accepted∩pool_only）
   与保留的 ref 点在 denom 上几乎无差别（171 vs 171）⇒ 选择器只偏好"观测多"，
   不额外偏好"观测多但未覆盖"。
3. **换位方向与 TopoGS"覆盖饱和"论断同向**：
   - 换入点：`mean_grad ≈ 0.00017`（**弱于**参考阈值 0.0002），但 denom 高（171）
     = "反复渲染的已覆盖区里的弱梯度点"；
   - 换出点：`mean_grad ≈ 0.00026`（达到参考阈值），但 denom 低（9）
     = "低观测强梯度点"（可能是新出现表面/动态边界）。
   - ⇒ **持久性排序把"新出现的强梯度"换成"反复看到的弱梯度"**。往已覆盖区加高斯
     不改善 ATE（与 TopoGS 的覆盖饱和一致），还占掉预算、抬高终态高斯数。

## 3. 对 Phase 0 结论的贡献

- **否定一个候选解释**：机制不是"在低覆盖区插入多余高斯"（§1.2 显示换入点
  是高观测点，不是低覆盖点）。
- **支持一个候选解释**：机制是"在已覆盖区重复造高斯"（§1.3）。这与
  `diag_person_tracking_degradation_2026-10-29.md` §3 的"覆盖饱和"假设**同向**，
  但现在是直接读数，不是推断。
- **不改判 Phase 0**：Phase 0 已按三 seed 3/3 退化 + 3/3 膨胀 + 逐帧块自助判
  "小幅真实退化"。本诊断解释**为什么**退化，不推翻退化本身。
- **对"换信号源"族的一般性启示**：`denom`（或任何"被看到次数"类信号）天然偏向
  已覆盖区；除非排序键同时引入"未覆盖/新出现"的奖励，否则此类机制的结构性
  倾向就是把预算花在饱和区。这与 TopoGS 的 `N = Θ(|M|/δ²)` 覆盖饱和论证一致。

## 4. 边界

- 单序列单 seed（person_tracking seed0）；trace 只覆盖 on 臂（off 无选择器
  不落 trace，阴性对照成立）。
- trace 未记录尺度（clone/split 分界）与"该点事件后是否存活"（后续 prune 是否
  剪掉换入点）；这两项需要下一次带 trace + 存活标记的 run 才能补。
- "已覆盖区"是**推断**（高观测 ≈ 反复渲染 ≈ 覆盖）——像素级投影验证需要
  事件↔位姿对齐，留待后续。

## 6. 本文件不主张什么

- 不主张"BPW 失败根因 = 覆盖饱和"（单序列单 seed，且"覆盖"是推断）；
- 不主张"任何持久性类机制都无效"（TopoGS 用构造式初始化绕开在线致密化，TAD-GS 用
  寿命感知阈值，不是同一个信号）；
- 不主张"换信号源"族全部到此为止——但**下一次尝试若还是"被看到次数"类信号，
  必须先解决"信号天然偏向已覆盖区"这个问题**（这是本诊断给出的结构性约束）。
