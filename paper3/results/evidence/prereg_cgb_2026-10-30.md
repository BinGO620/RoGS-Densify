## 0. 为什么不是"再换一个排序键"

本轮离线预筛（`prescreen_ranking_keys.py`，pt seed0 trace，零 GPU）给出两条硬读数：

1. **BPW 的失效不是"偏向已覆盖区"，而是"同预算重排"。** 参考集内
   `Spearman(mean_grad, denom) = 0.069` ⇒ 用 denom 加权等于以梯度为权的**独立重抽**。
   BPW 只换掉 11.6% 的槽、总额梯度只掉 2.3%，ATE 却 3/3 退化、终态高斯 1.30×。
   ⇒ **固定源点预算下，任何重排都付代价**，代价与"换了多少梯度"几乎无关。
2. **"换入点梯度低于 τ_base"是池定义的算术后果，不是发现。** 池 = `grad ≥ τ_lo`、
   参考集 = `grad ≥ τ_base` ⇒ 非参考点必然 < τ_base（实测 9/307064 条为浮点边界）。
   上一轮诊断的这条断言必须按"定义使然"读，不得当机制证据。

⇒ 第 11 次尝试**不再做同预算重排**。改做**加法干预 + 等剂量控位对照**：
保留参考选中集**一位不动**，另加 m 个源点；两臂 m 相同、唯一的差别是**位置怎么挑**。

> ⚠ **2026-10-30 实测更正（原文不追改）**：本节的「两臂等剂量」是**设计意图**，
> L1 实测显示它**只在事件 1 成立**（2638/2638）；从事件 2 起两臂地图分叉、`ref_sel` 分叉，
> 共同事件 Σ 差 **+7.79%**。⇒ **「等剂量控位对照」在本装置上不可构造**。
> 证据与根因：`verdict_cgb_l1_2026-10-30.md` §4；装置地板：`cgb_dose_floor_2026-10-30.md`。
> 读取本文其余章节时，「等剂量」「剂量严格相等」一律按**设计意图**读，不得当作读得的性质。

这同时补上 `audit_legacy_densification_2026-10-27.md` §4 指出的历史缺口——
A4「激进 clone −29.4%」的增益与 2.1–6.5× 高斯数混杂，**无法区分"更多"与"更对"**。
本设计把这两件事拆开。

## 1. 假设

> **H1（放置可分离）**：在**源点数增量相同**的前提下，把新增源点放在"空间稀疏处"
> （`CGB`）比放在"梯度最强处"（`GRAD`，即把参考阈值继续放低的渐进版）更能改善跟踪。

- H1 成立 ⇒ 存在一个**放置效应**，与剂量无关 ⇒ 这是可主张的正面机制。
- H1 不成立（`CGB ≤ GRAD`）⇒ "更多"就是"更多"，空间分布不是杠杆 ⇒ 本族止损。
- 两臂都劣于 `off` ⇒ **剂量本身有害**（与 BPW 的 1.30× 膨胀同向），本族止损
  （不改判 BPW 的既有结论）。

**关键的可分离性**：两臂的 `|accepted ∪ extra|` 逐事件**严格相等**（由同一
`floor(f × budget)` 生成），且 `extra` 全部取自同一候选池（`grad ≥ τ_lo`、且不在
`accepted` 内）。两臂的差别只有排序键一个是 `g·s^γ`（γ=1）、一个是 `g`（γ=0）。

## 2. 机制定义（一句话可复现）

每个 densify 事件：

```
ref_sel  = { i : g_i >= τ_base }                      # 参考臂的选中集，本机制不动它
budget   = |ref_sel|
extra_k  = floor(swap_frac × budget)                  # 增量源点数（两臂相同）
pool     = { i : g_i >= τ_lo } \ ref_sel              # 候选（τ_lo = tau_low_factor·τ_base）
key_i    = g_i · s_i^γ                                # γ=0 → 纯梯度续填；γ=1 → 稀疏加权
extra    = pool 内 key 最大的 extra_k 个
选中     = ref_sel ∪ extra        （选中者阈值 −1.0，其余 +inf；percent_dense 一律不变）
```

`g_i = accum_i / max(denom_i,1)`（与参考臂同一口径，**不引入 denom 加权**）。

`s_i` = 空间稀疏度，由**当前全图** xyz 的体素计数给出（自校准，无标定常数）：
`cell = alpha · (V/N)^(1/3)`（V = 当前 xyz 的包围盒体积，N = 当前高斯数，alpha=1.0），
`n_i = i 所在格及其 26 邻域的计数`，`s_i = n̄ / n_i`（`n̄` = 全图 n 的中位数）。
⇒ `s_i > 1` = 比中位数稀疏。

## 3. 装置（L1：2 新 run + 复用 off）

| 项 | 值 |
|---|---|
| 序列 | `person_tracking`（580 帧，有 headroom，效应可见） |
| seed | 0（L1 筛选单 seed） |
| 臂 | `off`（复用既有 run）、`cgb_g1`（γ=1）、`cgb_g0`（γ=0，等剂量控位对照） |
| `swap_frac` | **0.05**（= 每事件 +212 源点；Σ 增量 ≈ 0.05×271,931 ≈ 13,600） |
| `tau_low_factor` | 0.5（沿用 BPW） |
| 配置 | `configs/experiments/paper3_bpw/cgb_{g0,g1}_person_tracking.yaml` |
| 机器 | **本地 2060**（远程 3090 不可达；本地产物按 G-算力条标注"非权威"，**不进论文表**） |
| 时长 | 单 run ≈ 45 min 在线 + 45 min color refinement |

**为什么 swap_frac=0.05 而不是 0.2**：预筛表（Q4）显示 f 越大，换入点的平均梯度越低
（0.05→−31%、0.20→−35%），边际信息增益小、剂量风险大。5% 是"能看见方向"的最小剂量。

## 4. 读数（分开报，禁止合并成一个"效果"数）

- **R1 机制门（确定性，第一判据）**：逐事件 `n_added_on − n_added_ref` 必须严格等于
  `floor(swap_frac×budget)`；`extra` 的 `mean s` 必须显著高于 `ref_sel` 的（γ=1 臂）；
  γ=0 臂的 `extra` 的 `mean s` 必须与 `ref_sel` **接近**（**2026-10-30 补落点**：
  接近 = `mean(s)_extra / mean(s)_ref < 1.2`；仅作报告项，不参与 PASS/FAIL）。
  任一不成立 ⇒ **装置失效**，先修装置。

  > ⚠ **2026-10-30 证据通道更正（审查 M4）**：原文写"证据：console `[cgb]` 行"，
  > 但实测落盘 `console.log` 里 `[cgb]` 的方括号被 rich 标记吞掉（`grep -c 'cgb\]'` = 0，
  > 而行本身在：`grep -c 'iter=.*gamma'` = 63）。实际可读通道是
  > **runner 级 tee 日志**（`evidence/cgb_l1_l1_*.log`）与 **选点 trace CSV**。
  > 读取本预注册时，"console `[cgb]` 行"一律按"runner 日志中的 `iter=… gamma=…` 行"读。
- **R2 剂量（报告项）**：终态高斯数三臂对照。等剂量若在源点层成立而高斯层不成立，
  按 `PREREGISTRATION.md` §3.1 P0-A-2 的方式并陈两个口径，不单选对自己有利的。
- **R3 方向（ATE）**：`Δ(on − off)` 与 `Δ(cgb_g1 − cgb_g0)`，逐 seed 报原始值。
  **单 seed ⇒ 一律记"不可判"**（pt 逐序列地板 3.83cm，n=1 无法谈显著性）；
  ATE 只作**方向参考**，不得写"改善/退化"以外的判定词。

## 5. 功效核算（§3.2(b) 强制项）

- 来源：`seq_floors_2026-10-30.json`，`person_tracking` 地板 **3.83 cm**（E1/E2/E3 取 max）。
- 该值的来历：r33 同批 4 臂 × 3 seed 的逐 seed ATE / 配对差 sd，`MDE(95%,n=3)=t·sd/√3`。
- **n=1 本实验设计不可能判出任何 |ΔATE| < 3.83cm 的效应**——这是**设计层面的已知缺陷**，
  按 §3.2(b) 必须在设计阶段声明，不得跑完再解释。
- 因此本 L1 **改判据层级**：主判据 = R1 机制门 + R3 的**方向一致性**（三臂排序是否
  与 H1 预测一致）；ATE 绝对量只作"是否出现 >3.83cm 的量级异常"的看门狗。
- 要真正判 H1 需要 n=3 的 `g0`/`g1` 配对（`MDE(95%,n=3)` 才可用）⇒ **L1 通过后**再补
  seed 1/2，不在本轮做（渐进阶梯：探索省采样）。

## 6. 机械判定规则（看数据前锁定）

L1 的出口三选一，按顺序机械应用：

1. **装置失效**：R1 任一子项不成立 ⇒ 冻结读数、修装置、按原判据重跑。**不得**解释机制。
2. **剂量有害**：`cgb_g0` 与 `cgb_g1` 的 ATE 都 ≥ `off` + 1.0cm（方向同 BPW），
   且两臂终态高斯数都 > `off` 的 1.15× ⇒ 判"加法剂量有害"，**本族关闭**，
   记入 `NOTES.md`「已排除方向」（与 BPW 并列，不合并叙述）。
3. **放置可判**：两臂 ATE 都不触发第 2 条，且 `cgb_g1 < cgb_g0`（方向一致，幅度任意）
   ⇒ **进 L2**：补 seed 1/2 + 一条不同类型序列（`balloon` 非退化 + `crowd` 密度），
   并先把 `ΔATE(g1 − g0)` 的 n=3 配对 MDE 重算一遍（用本轮 L1 的 seed 间散布）。
4. **放置无效应**：两臂 ATE 都不触发第 2 条，但 `cgb_g1 ≥ cgb_g0` ⇒ 记"放置无效应"
   （H1 证否），**本族关闭**，写进 `NOTES.md`「已排除方向」。

> 规则 3 的"方向一致"是**弱门**（单 seed 无可判性）。它的作用是决定**要不要花钱补 seed**，
> 不是决定"机制成立"。措辞上不得把 L1 的方向一致写成"证实"。

## 8. 与既有已排除方向的关系

- **不是**"抑制致密化"族（A2/A5/A6，2026-09-02）的复活：本机制**增加**源点，不减少。
- **不是** BPW 的参数变体：BPW 已被 P3-D2-007 判为测量性收口对象；本机制不消费
  `denom`，且不动 `ref_sel`。
- **是** A4「激进 clone」的受控版：A4 = 全局降阈（2.1× 高斯），本设计 = 降阈但
  **只取 5%**，并加一个**等剂量的位置对照**——这正是 A4 缺的那一半。
