# 研究问题与边界

## 1. 背景

3D 高斯泼溅的地图质量不仅取决于损失函数，也取决于高斯何时被 clone、split 或保留。
在动态场景 SLAM 中，动态区域的残差可能很大，但它们的监督往往短暂且不连续；静态区域则需要稳定的几何支撑。直接套用静态场景的致密化规则，可能得到高斯数量增加却跟踪变差的结果。

## 2. 核心问题

> 在动态场景 SLAM 的在线建图过程中，能否利用有效观测持续性与可靠性信息，改善高斯的致密化决策，使地图获得更充分的几何支撑，同时不把动态残差无条件地转化为地图增长？

## 3. 当前工作假设

**H1：** 只要把动态区域的像素权重直接加入损失函数，不能稳定解决致密化问题，因为 clone/split 的触发和高斯数量变化会形成连锁效应。

**H2：** 比逐像素损失加权更接近问题本质的做法，是把有效观测次数、可见性持续性和可靠性统计接入致密化判据，而不是只改变单帧 loss。

H1 是已有实验的动机，不把它写成论文 3 的新贡献。H2 只有在新实验通过预注册门槛后，才可成为方法主张。

## 4. 研究三的候选机制

Phase 0 只验证一个最小机制，不同时实现完整的 VAD、寿命阈值、时间形变和动态层管理：

- 以有效观测计数或连续可见性作为高斯级状态；
- 对致密化触发增加最小观测条件或寿命相关阈值；
- 对动态残差保留保守策略，避免把单帧异常直接放大为 clone/split。

最终采用哪一种由实现代价和 Phase 0 数据决定，不能先把候选机制写成既成结论。

## 5. 边界

本研究不以显式恢复动态物体、运动场估计、4D 形变或动态新视角合成为目标。face-dynamic 文献用于说明问题边界，DynPort-Offline 的 4D 层序列结果用于解释为什么“保留动态内容”和“改进静态地图致密化”应分开处理。

研究对象是动态 RGB-D SLAM 中的在线高斯地图生长。主要终点是跟踪误差与地图生长统计，渲染指标用于检查是否出现明显的地图质量代价。

## 6. 贡献准入

只有满足以下条件，才允许在论文中写成正面方法贡献：

1. 至少一个不同类型的场景上通过预注册的最小效果门；
2. 跟踪指标没有被机制性恶化；
3. 高斯数量或地图质量的变化可以由工件追溯；
4. 与最小对照相比，效果不是单纯来自增加计算预算或无条件增加高斯数量。

否则只记录为研究边界，不进入贡献栏。
