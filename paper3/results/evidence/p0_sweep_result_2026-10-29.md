## 2. 预注册正确性门 R1

预注册要求 p0=0 的逐事件 `budget` 序列与 off 逐事件相等（C1）。

- 五个 persistence run 的首事件 `budget` 均为 2,638，符合首事件硬门。
- 但 off 臂没有选择器日志，现有 off artifact 未落盘逐事件 `budget` 序列，因此本次**无法执行 C1 的完整逐事件比较**。
- p0=0 的实现实际使用 `p0=max(0,1e-6)=1e-6`，不是严格数学意义的 0。
- 结论：**R1 = INDETERMINATE，不是 PASS**。因此不能声称“p0=0 严格复现 off”。

这不是事后改门：该限制已经在预注册文件中写明；本批的 p0 结果仍可作为诊断性读数，但 C1 未验证。

## 4. 按预注册 R2–R5 落判

- **R2（收缩项有害、强度依赖）= 不成立**：虽然 p0=2、128 比 p0=8 更差，但相邻点不具备至少两段同向单调变差；p0=0 和 p0=32 反而更好。
- **R3（收缩强度在 [0,128] 内不可分辨）= 不成立**：存在超过 0.62 cm 的 p0 间差异。
- **R4（收缩项有益且方向跨点一致）= 不成立**：方向不一致。
- **R5（非单调/不可判）= 成立**：扫描显示明显的非单调、高方差响应。

机械结论：**p0 扫描不可支持“收缩项单调有害”或“收缩项单调有益”。它只排除了简单的单调强度解释。**

## 5. 额外边界

1. 本扫描只有 person_tracking、seed 0；它不是总体效应量估计。
2. 事件数和 `Σbudget` 也随 p0 变化：66–70 个事件，`Σbudget` 294,858–323,823。由于地图状态会随选择位置改变，后续事件的预算并非严格固定；这与 Phase 0 已知的装置非确定性/内生剂量问题一致。
3. 终态高斯数从 54,219 到 72,786，进一步说明不能把终态地图大小当作严格剂量等价证明。
4. off 没有落盘逐事件选择器摘要，因此本次不能完成严格的 p0=0 逐位复现校验；若要补 C1/C2，必须先加诊断日志并重跑 traced run。

## 6. 对研究方向的含义

当前最稳妥的解释不是“把 p0 调到某个值即可修好”。数据支持的是：

- p0=8 的退化不能被单调归因于收缩强度；
- 单 seed 的 p0 响应非单调，且跨点波动超过 0.62 cm；
- 三 seed Phase 0 的 on−off 配对差为 `+0.2219/+0.4995/+2.9327 cm`，均为退化方向，均值 `+1.2180 cm`，但只有 seed 2 单独超过 0.62 cm；
- 因此下一步不应继续盲扫 p0，而应转向**预算-精度曲线**或**选点覆盖缺口诊断**，并把当前 BPW 作为未通过的候选机制，不再包装成已验证贡献。

**当前判决**：Phase 0 仍未通过；p0 扫描为 `R1 INDETERMINATE / R5 非单调，不支持收缩项单调解释`。
