# 装置稳健估计量框架 v2（丙 prereg；此后新机制族的判据框架）—— 2026-11-05

**状态**：判据锁定于任何新族 run 之前。账本：`P3-D2-025`（用户拍板「继续研究」=
按默认执行，`P3-D2-011` 先例）。依据：`P3-D2-023`（自差 +96.8%）+ `P3-D2-024`
（确定性套件无效，R2 丙坐实）+ `DISCIPLINE.md`「测量口径」6（装置自差准入门）。
**适用范围**：论文 3 此后**新开**的机制族（E1①/E3 已按 `P3-D2-030` 修正，见 ⛔ 标记）；不追溯改写已关闭族（BPW/CGB/FDose/
MaskStat/剂量-响应 判决维持，见 §5）。

## §0 为什么需要框架 v2

P3-D2-024 证明：3090 上臂级终态比较（ATE / 高斯数）的判效力被管线非确定性
支配（确定性套件全开仍 +65.3% 分叉），且**不可修复**（torch 官方套件不覆盖
custom CUDA 栅格化 backward；最优先机制候选 = 其 atomicAdd——候选推断，
算子未定位，见 `prereg_divsrc_bisect_2026-11-05.md` §3 的两读法）。因此 v1
框架的「臂级 ATE 主判据」在新族上没有判力——框架 v2 把判据重心移到装置噪声
碰不到的读数上。

## §1 判据三层（优先级从高到低；E3 永不产生出口）

- **E1 机制门（装置无关；主判据，PASS/FAIL 可判）**：
  ① 两态单测：config 开关默认关 = **单测级数学路径全等**（CPU/单算子级断言）；
  ⛔ **「run 级逐位一致在本装置不可达」一句自 2026-11-05 起作废**（`P3-D2-030`
  仪器模式：单线程 + det-raster ⇒ 40 帧 ×2 逐位一致，见
  `prereg_instrument_mode_2026-11-05.md` §4）。现行读法 = **仪器模式下 2 run
  逐位一致（R-valid）为强制前置**，通过后 E1① 的两态单测照常执行；
  ② 机制作用量证据 = trace 激活计数/逐 KF 落盘 CSV（静默组件
  必须有落盘证据，`DISCIPLINE.md`「组件生效验证」#9）；③ 机制输入量（w 分布、
  事件 budget 序列、排除表等）在两臂**各自内部**的可复算性。
- **E2 逐事件配对（次判据；只允许「分叉/不分叉」级别结论）**：
  同 `rng_sequence` 下逐 densify 事件的机制输入量配对差，报 **median + IQR**。
  **机械判定规则**：跨臂 Δ 中位 **≥ 2 × 地板中位**，且**两参照**（每臂各自的
  同臂重跑逐事件地板）方向一致 ⇒ 允许写「跨臂行为分叉」；否则 = 「装置分辨率
  内不可判」。
  **地板口径（锁定）**：逐事件装置地板必须在**与跨臂批相同的确定性状态**
  （det-ON/OFF 一致）下、用**同事件载体**（两臂都有逐事件机制输入量落盘，
  如 trace CSV，config 门默认关）测得——off 臂现有 3 样本为 det-OFF 且无逐事件
  落盘，**不得**充当逐事件地板。
- **E3 臂级终态（ATE / online/refined 高斯数 / 渲染指标）**：
  ⛔ **自 2026-11-05 起按口径二分**（`P3-D2-030`）：
  - **仪器口径**（单线程 + det-raster ON）：逐位可复现 ⇒ 臂级终态**可判**，
    但必须标 `mode=instrument`，且绝对值不得与文献/前作直接比；
  - **async 口径**：仍作 **「自差内不可判」** 边界交代
    （3090 包络 −30%~+97%、ATE ±2.14cm；见 `device_floor_3090_2026-11-05.md`）。
  两口径读数**永不混引**；任何出口都不产生「评测协议 = 贡献」的主张（§4）。

## §2 出口规则（机械，按序）

1. E1 任一不过 ⇒ 装置/机制失效，冻结读数修复重跑，不得解释结果；
2. E1 全过 + E2 超地板同向 ⇒ 允许写「机制有跨臂行为分叉」（方向如实记录）；
   **注意这不是效果主张**——ATE 收益在 E3 不可判下永远不存在；
3. E1 作用量读数与对照不可区分（share 类 < 5% 等，按族 prereg 写死）⇒ 机制
   无作用量，止损记「已排除方向」；
4. E2 落地板内 ⇒ 「不可判」，与 2/3 同条目并列记录；
5. 任何出口都**不产生贡献主张**（§4）；判效批派发前仍过 slam-critic G3。

## §3 功效核算前置（强制，`paper3/PREREGISTRATION.md` §3.2(b) 同款）

任何 E2 判读前必须先落：① 逐事件装置地板（同臂重跑 ≥3 样本的中位相对差）；
② 每臂 n（E2 配对读数建议 n≥3）；③ 「若真实效应小于 MDE，本设计不可能判出」
的显式声明。缺①的设计 = 缺陷，须在派发前补（加 run 或换配对口径）。

## §4 贡献边界（用户 2026-11-05 重申，成文）

- 测量性结论、装置敏感度、本估计量框架、装置门标定、一切「不可判」类读数
  = **评测卫生与边界讨论**：可进方法节/讨论节，**不进贡献栏、不作 headline、
  不与机制贡献并列计数**（`DISCIPLINE.md`「论文叙事纪律」评测协议条款）。
- 机制贡献的唯一来源 = E1+E2 正面读数支撑的机制主张，且通过「组件准入 =
  叙事服务」检验（读者看到的系统/表里跑着它、它的有无改变读者看到的数字）。
- 负结果只以边界小节/讨论身份存在：不包装性命名、不进贡献栏、不写机制解释
  当结论（`DISCIPLINE.md` 负结果处理）。
