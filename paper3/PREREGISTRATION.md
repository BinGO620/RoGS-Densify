# 论文 3 实验预注册（草案）

**状态**：Phase 0 判据已于 2026-10-27 锁定（§3.1），先于任何 Phase 0 run 提交。
**原则**：本文件先于新机制代码和正式实验生效。数字、阈值和场景一旦锁定，不因结果修改。

## 1. 比较对象

- `off`：当前共享代码与配置的致密化策略，作为基线。
- `on`：只增加一个最小的高斯级有效观测/生命周期判据，其余训练、采样、优化和预算保持不变。
- `negative-control`：不使用有效观测信息的等计算量对照，用于区分“机制信号”与“单纯增加致密化预算”。
  旧族安慰剂范式（B4d 确定性置换信号、剂量分布与 on 相同）已验证有效，Phase 0 沿用。

具体配置文件、代码 commit 和随机种子在派发前写入 `paper3/results/evidence/manifest_phase0.json`。

> **审计注（2026-10-27）**：本预注册继承旧族纪律教训——战场不得选
> moving_obstructing_box（基线 44cm 无竞争力，见 `results/evidence/audit_legacy_densification_2026-10-27.md` §2.3）；
> 判据锚定绝对 ATE（≤5cm，目标 2–3cm）；A4/B1 全局激进 clone 只作参照锚点，不并入 on。

## 2. 阶段设计

### Phase 0：最小生死验证

规模为一个主场景或最多两个主场景、一个随机种子、2–4 个 run。必须包含 off、on 和必要的 negative-control。选择场景的依据写入 manifest，不根据结果中途替换。

交付三件套：

1. 跟踪指标表，至少包含 ATE、帧数和失败状态；
2. 渲染指标表，至少包含全帧与可用的静态/动态分区指标；
3. 渲染图与原图对照，包含重点帧和放大区域。

### Phase 1：场景类型泛化

只有 Phase 0 通过才启动。增加 2–3 个不同类型场景，每个配置先用一个种子。至少 2/3 场景类型达到 Phase 0 同一方向的门槛，才进入 Phase 2。

### Phase 2：正式批

只有 Phase 1 通过才启动。扩展到预注册的全序列和多随机种子，统一报告运行时间、显存、高斯数量、跟踪和渲染结果。

## 3. Phase 0 判据（草案，已被 §3.1 取代）

> ⛔ **本节已被 §3.1 正式判据取代（2026-10-27）**。以下草案条文保留作历史痕迹，
> 判决一律按 §3.1 执行。

以下阈值是草案，不是已锁定判据：

- `ATE_on <= ATE_off + 0.5 cm`，避免把跟踪退化误当成建图收益；
- 至少一个预先指定的地图生长指标相对 off 改善 ≥10%，例如有效静态支撑覆盖率、达到稳定高斯数所需帧数，或动态区误差；
- 高斯总数不超过 off 的 1.5 倍，避免用无约束增量换取表面收益；
- negative-control 不得复制 on 的全部效果，否则不判为机制成立。

正式锁定前必须回答：指标定义、分母、评估帧集、噪声地板、失败处理和多指标冲突时的优先级。

### 3.1 正式判据（2026-10-27 锁定；**跑实验前已提交**）

指标定义与分母：

- **ATE**：全帧 `ate_rmse_cm`（tracking_raw.csv 第 8 列），分母 = 序列总帧数；失败帧不剔除，失败即记 FAIL。
- **地图生长**：`online_num_gaussians`（efficiency_raw.csv），分母 = 同序列同 seed 的 off 臂值；
  增长率 = (on − off)/off。
- **渲染**：全帧 `psnr`（mapping_raw.csv），另报 `static_psnr` 与 `static_ghost_excess_depth_l1_cm`
  作为地图质量代价检查；渲染指标不用于判定跟踪方法好坏（审计 §2.1 的反相关教训）。

评估帧集：标准 Bonn 全序列（不抽帧）；渲染 eval 采用 run 内 `--eval` 全帧口径，
不使用离线 `render_compare.py` 的重采样子集作为判定依据（仅作配图与视觉对照）。

噪声地板：

失败处理：

- 一次 run 崩溃或状态非 OK ⇒ 该配置记 FAIL，不补跑凑数；
- 若某序列上 on 与 negctl 的最终高斯数差 > 2% ⇒ 判「剂量匹配不成立」，该 run 作废；

- 发现代码或仪器缺陷 ⇒ 先冻结判定，修复后按原判据重跑，不先改故事。

1. **ATE**（第一验收标准）；
2. **地图生长指标**（本机制的直接主张面）；

### 3.2 逐序列噪声地板与预注册功效核算（2026-10-30 修订；判决口径变更）

> **依据**：`DISCIPLINE.md`「测量口径」#1（分区/差值类指标须 ≥2 参照 + median/IQR，
> 禁单一常数）与 exp32 教训「先算可达域」。§3.1 原「0.62 cm 全局常数」**废止**。

**（a）地板 = 逐序列派生，不套常数。** 派生器 = `scripts/paper3_bpw/derive_seq_floors.py`
（机算，零手抄；极性门禁 `tests/paper3_bpw/test_derive_seq_floors.py` 5 条）。
数据源 = r33 同批同码 84 run（4 臂 × 7 序列 × 3 seed）。三套估计互为参照：

| 估计 | 定义 | df |
|---|---|---|
| E1 | 每个臂自身逐 seed ATE 的样本 sd（4 臂） | 各 2 |
| E2 | 每个非 baseline 臂逐 seed 配对差 (arm − baseline) 的 sd | 各 2 |
| E3 | E2 三臂残差合并（先减各自臂均值） | 6 |

`MDE(95%, n=3) = t(0.975, df) · sd / √3`。**地板 = 三套里最保守（最大）者**
⇒ 判「不可判」时不偏向任何一方。取值见
`results/evidence/seq_floors_2026-10-30.{md,json}`，摘要（cm）：

| balloon | balloon2 | crowd | crowd2 | crowd3 | person_tracking | person_tracking2 |
|---:|---:|---:|---:|---:|---:|---:|
| 0.50 | 0.72 | 0.57 | 1.88 | 0.56 | 3.83 | 1.89 |

**读法**：`|ΔATE| < 地板` ⇒ 记**「不可判」**（不是「通过」，也不是「未通过」）；
只有 `|ΔATE| ≥ 地板` 才允许写「改善 / 退化」。

**（a′）选最保守值的代价（如实登记）。** 取 `max(E1,E2,E3)` 是刻意偏向"判不出来"这一侧：
它永不产生虚假的「改善/退化」，但会**过度保守**——E2 的逐臂 sd 里混有真实机制异质性
（如 swbaonly 臂逐 seed 对 baseline 的差本身就带机制摆动），把它当纯噪声会高估地板。
因此：**单次判读应优先报"该臂对"自己的 E2**，`max` 值只作上界与交叉核对。
若某个结论只在用 `max` 时才"不可判"、用该臂 E2 时"超地板"，须在判决书里**两值并陈**，
不得只报对自己有利的那个。`person_tracking` 三种取法给出的值分散（见
`seq_floors_2026-10-30.json` 的 `E2_paired_sd` 与 `E3_MDE3`）——
**任何单一数字都不足以支撑断言**，故该序列在 n=3 口径下的结论只能写「不可判」。

**（b）预注册必须先算 MDE，再定判据。** 任何新实验的预注册文件必须含一段
「功效核算」：给出该序列**逐 seed 配对 sd 的来历**（哪批数据、哪一列）与
`n` 下的 MDE，并明确「若真实效应小于 MDE，本实验设计不可能判出」——
这属**设计缺陷**，须在设计阶段改（加 seed / 加序列 / 换配对口径），不得等跑完再解释。

**（c）既往判决不追溯改写。** 2026-10-28/29 已落的判决书按当时锁定的 0.62 常数执行，
**原文保留**。本节的更正只对**此后**的判据生效。同时如实登记一条**方向相反**的影响：

- pt1 `ΔATE(on − off) = +0.2219 cm` 的旧标签「临界（0.62 内）」在逐序列地板 3.83cm
  下应读作**「不可判」**；`ΔATE(on − negctl) = +1.4219 cm` 的「未通过」同理降级为
  **「不可判」**。
- **但这不是对机制的支持证据**：三 seed 方向 3/3 同向变差、终态高斯比 3/3 膨胀
  （见 `STATUS.md` §1），且逐帧配对块自助显示退化真实存在。改口只改变**标签**
  （从「已判有害」变成「跨 seed 口径判不出来」），不产生任何正面信号。
- Phase 0 的门状态因此**不变**：既然连「≥ 地板 的改善」都从未出现，P0-B/P0-C 都不满足
  ⇒ Phase 0 仍未通过。**不得**以本节为理由复开 BPW 族（用户 2026-10-30 已拍板转测量性结论）。

## 4. 禁止的事后调整

- 不因某个场景结果不理想而换场景；
- 不把均值达标改写成逐序列达标；
- 不把高斯数增加本身写成质量提升；
- 不用新指标替换失败的预注册指标；
- 不把负结果包装成新的 headline。

## 5. 进入下一阶段的机械条件

- Phase 0 未通过：只允许一次有独立证据支撑的定位修正，之后关闭该候选机制；
- Phase 0 通过：进入 Phase 1，并保留 Phase 0 全部工件；
- Phase 1 通过：进入 Phase 2；
- 任一阶段发现代码或仪器缺陷：先冻结判定，修复后按原判据重跑，不先改故事。
